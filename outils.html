Un déroulé simple pour vos exercices

  1. Décrire l’objectif et le résultat attendu.
  2. Préparer une première version avec l’aide de l’IA.
  3. Lire le code, le tester et corriger les erreurs.
  4. Enregistrer les changements dans GitHub, puis publier.
